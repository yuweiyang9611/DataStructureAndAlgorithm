# 从这里开始

不用先读完整个仓库。选一个最接近你的目标的入口，先完成 10 分钟闭环：读一个不变量、打开实现、运行测试、查看一次 Trace。

## 10 分钟快速开始

1. 打开 [阶段一至三](/主线/阶段一至三)，读“线性结构”或“查找与排序”中的一个主题。
2. 在 [学习单元](/学习单元) 中找到对应单元，打开真实源码与测试。
3. 复制该单元的 `dotnet test ... --filter ...` 命令并运行。
4. 在 [Trace 实验室](/追踪实验室?trace=radix) 逐步查看基数排序，说明每一轮为什么仍然稳定。
5. 能口头说出“不变量、复杂度、一个边界测试”后，再勾选完成。

## 本地准备

```powershell
dotnet --version
dotnet restore DataStructureAndAlgorithm.slnx
dotnet test DataStructureAndAlgorithm.Test/DataStructureAndAlgorithm.Test.csproj -c Release
```

项目目标版本是 `.NET 10` / `C# 14`。如果完整测试需要较长时间，先从 [学习单元](/学习单元) 复制一个窄范围筛选命令。

## 一次学习循环的完成标准

- 能用自己的话描述输入、输出和异常边界。
- 能写出结构或循环维护的核心不变量。
- 能解释复杂度中的每个变量，而不只背结论。
- 能指出实现文件和至少一个验证边界条件的测试。
- 能手算最小样例；有 Trace 的主题能解释相邻两步为什么变化。
