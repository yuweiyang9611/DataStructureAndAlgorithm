# 综合项目总览

综合项目用于检验能否把局部算法组合成端到端系统。每个项目都要求明确目标函数、失败边界、确定性规则和独立验证方法。

## 四个项目

1. [城市即时配送](/综合项目/城市即时配送)：最短路、缓存、连通性和最小费用最大流。
2. [迷你搜索引擎](/综合项目/迷你搜索引擎)：位置索引、BM25、Trie、BK-tree 与 Top-K。
3. [项目调度](/综合项目/项目调度)：DAG、关键路径、堆、区间结构与精确搜索。
4. [迷你存储引擎](/综合项目/迷你存储引擎)：B+ 树、Bloom Filter、LFU 与 WAL 恢复。

随后阅读[工程原则与证据链](/综合项目/工程原则与证据链)，并按[八周路线与验收](/综合项目/八周路线与验收)产出可以复查的测试、追踪和性能证据。

需要连续阅读时，可打开[完整综合项目单页](/综合项目实战学习指导)。
