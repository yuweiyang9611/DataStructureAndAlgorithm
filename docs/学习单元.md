# 学习单元与本地进度

不要把“读过文档”当成“掌握算法”。这里把仓库整理成 22 个学习单元；每个单元需要答对一题自测，并完成解释不变量、运行与扩展测试、迁移或构造反例三类证据。验证和复习状态只保存在当前浏览器。

## 本地进度与备份

本页使用浏览器 IndexedDB 事务保存学习记录，同一站点的标签页会同步进度。导出 JSON 可用于离线备份和跨设备迁移；导入先预览新增、更新、删除与忽略数量，确认后按单元更新时间合并，相同时间保留当前记录。请先校准不同设备的时钟。

旧版记录只迁移一次。重置会保留删除标记，避免旧页面或较旧备份复活已清空的记录。浏览器禁止存储时，页面会提示尚未持久化；本次学习仍可继续，并可以导出备份。
