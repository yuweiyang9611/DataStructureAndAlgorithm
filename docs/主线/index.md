# 主线路线总览

主线适合第一次系统学习数据结构与算法。不要按文件数量推进；每一阶段都要完成“解释不变量、运行或扩展测试、迁移到新问题”三类证据。

## 推荐顺序

1. [环境与学习方法](/主线/环境与学习方法)：准备 .NET 10，并建立契约、边界与复杂度意识。
2. [阶段一至三](/主线/阶段一至三)：线性结构、数组模式、查找与排序。
3. [阶段四至六](/主线/阶段四至六)：树、堆、字符串、图、动态规划与回溯。
4. [阶段七至八与测试证据](/主线/阶段七至八与测试证据)：综合项目、性质测试、变异测试与性能证据。
5. [练习、验收与后续](/主线/练习验收与后续)：用验收清单确认能否独立迁移方法。

## 现在开始

打开 [学习单元](/学习单元)。页面会根据前置依赖和本地掌握记录推荐下一步；只有自测答对并完成证据清单，单元才会标记为“已验证”。
