## 建议的阅读循环

1. 在学习指导里写下输入、输出、非法输入和规模边界。
2. 在源码里标出必须始终成立的不变量。
3. 用三到五个元素手算一次状态变化。
4. 找到对应测试，解释每个断言保护的行为。
5. 运行 Demo 或 `--trace json` / `--trace mermaid`，对照手算结果。
6. 最后才看覆盖率、变异报告和 Benchmark，分别判断测试触达、断言敏感度与性能趋势。
