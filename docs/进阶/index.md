# 进阶路线总览

进阶路线不是简单增加结构数量，而是训练三件事：公开契约能否跨实现保持一致、复杂状态能否由不变量约束、优化收益能否由独立证据支持。

## 推荐顺序

1. [十八周计划与验收](/进阶/十八周学习计划与验收)：了解阶段目标和退出标准。
2. [核心数据结构](/进阶/核心数据结构)：哈希、并查集、缓存、区间结构和有序集合。
3. [正确性修复与结构补强](/进阶/正确性修复与结构补强)：比较器、平衡约束与失败原子性。
4. [算法专题](/进阶/算法专题)与[高阶算法和内存](/进阶/高阶算法与内存)：高级图、字符串、动态规划和内存所有权。
5. [持续集成、追踪与测试证据](/进阶/持续集成追踪与测试证据)：把性质、状态机、覆盖率、变异与基准连成证据链。

## 进入条件

建议先完成主线中的线性结构、排序、树、图和动态规划。打开[学习单元](/学习单元)时，尚未满足的前置会明确显示，不需要靠目录顺序猜测。

需要连续阅读时，可打开[完整进阶单页](/CSharp数据结构与算法进阶学习指导)。
